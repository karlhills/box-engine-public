# Collector (Luau)

The M3 sample game rewritten as a data project: no Rust, only scenes, assets and Luau scripts, played by the stock `box-player` and the editor. Walk the procedural skinned humanoid around an arena and collect every gem. When the arena is empty the game switches to the next one (`arena` → `arena2` → `arena` …) and keeps your score.

**Controls.** WASD, arrows, d-pad or left stick move relative to the camera (a light push walks, full input runs). Space or gamepad South jumps. The right stick turns the camera; click to lock the mouse for mouse look. Escape, P or Start opens the pause menu (Resume, Save game, Load game, Language): d-pad or arrows move, South or Enter confirms, East or Escape closes.

**Run.**

```bash
cargo run -p box_player_app -- examples/collector_luau
cargo run -p box_player_app -- examples/collector_luau --scene arena2
cargo run -p box_player_app -- examples/collector_luau --capture target/captures/m7/collector_luau.png --frames 120
cargo run -p box_editor_app -- examples/collector_luau     # press Play
```

**Scripts** (`assets/scripts`):
- `player.luau`: `character.move` / `character.jump` from the `move` and `jump` actions, the body turned toward the movement, the animation state machine's `speed`, `grounded` and `jump` parameters, and a fall reset.
- `camera.luau`: the follow camera.
- `gem.luau`: spin and bob; on pickup a sound, `particles.burst` and the `collected` signal.
- `arena.luau`: switches scenes when the last gem is gone.
- `game.luau`: score, HUD, pause menu and saves; a persistent runtime entity.
- `util.luau`: shared helpers.

**Data.**
- `assets/animation/locomotion.animgraph.json`: Idle/Walk/Run/Jump.
- `assets/strings/{en,de}.strings.json`: all text.
- `assets/data/tuning.data.json`: character tunables, hot-reloaded.
- `assets/ui/collector.theme.json`
- `assets/settings/input.actions.json`
- `assets/models/character.glb`: from `cargo run -p box_proc --example gen_character`.

**Playtest.** `playtests/route.playtest.json` runs to the middle gem, back south and east to the south-east gem with the `move` action, and checks that both gems are gone, the pickup sound played, the score reached 20 and where the player is. Replay it headless (deterministic, exit 1 on a failed check):

```bash
cargo run -p box_cli -- playtest examples/collector_luau route
```

**Saves** go to `.box/saves/quick.save.json`: every saved entity plus each script's `on_save` data (score, jumps, gem bob centres).

**Editor completion.** `.box/types/box.d.luau` is generated by `cargo run -p box_cli -- script types --project examples/collector_luau`; `.vscode/settings.json` points luau-lsp at it. Regenerate after engine API changes (`m7_acceptance` checks it is current).

**Scenes are generated.** Edit `authoring/<scene>.commands.json`, then:

```bash
cp examples/collector_luau/authoring/empty.scene.json examples/collector_luau/assets/scenes/arena.scene.json
cargo run -p box_cli -- scene apply examples/collector_luau/assets/scenes/arena.scene.json examples/collector_luau/authoring/arena.commands.json
```

Tests: `cargo test -p box_engine --test m7_acceptance` and `cargo test -p box_editor --test m7_collector_luau`. The Rust original stays in `examples/collector`.
